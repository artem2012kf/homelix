# Данные квартир

Каталог больше не хранится внутри большого TypeScript-файла.

- `apartments.json` — ровно 15 квартир, их характеристики и список помещений.
- `apartment-layouts.json` — координаты каждой комнаты на SVG-плане.

Квартира связывается с планировкой через `layoutId`. В каждой записи планировки `roomId` должен совпадать с `id` помещения из квартиры.

Рабочая область плана:

- `x`: 58–728
- `y`: 58–538
- ширина: 670
- высота: 480

`lib/apartments.ts` проверяет количество квартир, уникальность ID, наличие планировки и соответствие комнат. Если JSON заполнен неправильно, сборка остановится с понятной ошибкой вместо публикации битого каталога.

Чтобы добавить или изменить квартиру:

1. Измените объект в `apartments.json`.
2. Создайте или обновите набор координат в `apartment-layouts.json`.
3. Проверьте совпадение `layoutId` и всех `roomId`.
4. Запустите `npm run build`.
