# Данные квартир

Каталог хранится отдельно от компонентов интерфейса.

- `apartments.json` — ровно 30 квартир из 15 городов России.
- `apartment-layouts.json` — типы помещений, доли площади и координаты комнат на SVG-плане.

Каждая квартира содержит `city` и связывается с планировкой через `layoutId`. Комнаты не дублируются в каждой квартире: они описываются один раз в планировке. Площадь помещения рассчитывается по `areaShare` от общей площади квартиры.

Требования к планировке:

- сумма `areaShare` должна быть равна `1`;
- координаты должны находиться внутри рабочей области `x: 58–728`, `y: 58–538`;
- `roomId` внутри одной планировки должны быть уникальными;
- тип комнаты должен соответствовать типам из `types/apartment.ts`.

`lib/apartments.ts` проверяет количество квартир, уникальность ID, наличие планировки и сумму долей площадей. При ошибке сборка останавливается до публикации некорректного каталога.

Чтобы добавить квартиру:

1. Добавьте объект в `apartments.json` и укажите город и `layoutId`.
2. Используйте существующую планировку или создайте новую в `apartment-layouts.json`.
3. При изменении количества объектов обновите проверку `EXPECTED_APARTMENT_COUNT`.
4. Запустите `npm run build`.
