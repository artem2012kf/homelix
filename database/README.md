# База данных проекта

В MVP есть два уровня хранения данных:

1. `lib/apartments.ts` — демо-каталог 30 квартир и комнат.
2. `data/database.json` — локальная серверная база для пользователей, избранного и бронирований.

Когда пользователь бронирует квартиру, запись появляется в `data/database.json`, а статус квартиры на сайте меняется на `Бронь`.

Для настоящего проекта используйте `database/schema.sql` как основу PostgreSQL/Supabase базы данных.

## Основные таблицы

- `users` — пользователи.
- `apartments` — квартиры.
- `rooms` — комнаты и SVG-координаты.
- `favorites` — избранное.
- `reservations` — брони.
- `furniture_items` — магазин мебели.
- `leads` — заявки клиентов.
- `chat_sessions` и `chat_messages` — история общения с ИИ.

## Важно

Локальная JSON-база подходит только для демонстрации. Для боевого сайта нужно подключить PostgreSQL/Supabase, хеширование паролей через bcrypt/argon2, email-подтверждение и защищенные серверные сессии.
