# Убрать цену из-под планировки

Что сделано:

- блок цены под планировкой удалён;
- стоимость с мебелью остаётся только в верхней карточке справа;
- список мебели под планировкой остаётся;
- кнопки "Повернуть" и "Убрать" остаются.

Замени файл:

components/ApartmentExperience.tsx

Потом открой:

app/globals.css

и вставь в самый конец содержимое:

ADD_TO_END_OF_app_globals.css

Проверь:

cmd /c npm run build

Потом:

git add .
git commit -m "убрать цену под планировкой"
git push -u origin main
