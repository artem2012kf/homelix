# Адекватные планировки и старые двери

Что сделано:

- планировка больше не берёт кривые координаты из базы как есть;
- компонент сам собирает нормальную схему квартиры по типам комнат:
  прихожая, санузел, кухня/гостиная, спальни, лоджия, гардеробная;
- комнаты занимают весь контур квартиры, без пустых дыр и огромных чёрных блоков;
- старые двери возвращены: белый проём + тонкая линия + дуга открывания;
- мини-планировки в карточках квартир тоже используют новый нормальный вид;
- мебель, перетаскивание и поворот под планировкой сохранены.

Замени файлы:

components/ApartmentPlan.tsx
components/ApartmentMiniPlan.tsx
types/furniture-placement.ts

Потом открой:

app/globals.css

и вставь в самый конец содержимое:

ADD_TO_END_OF_app_globals.css

Проверь:

cmd /c npm run build
