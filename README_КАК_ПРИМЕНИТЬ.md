Что изменено:

- первые 10 квартир теперь используют отдельные нормальные схемы планировок;
- студии, евро-2, 2-комнатные, 3-комнатные и 4-комнатные собираются по разным аккуратным шаблонам;
- комнаты больше не берутся как кривые старые полигоны;
- вернулись старые двери: белый проём + линия + дуга;
- двери ставятся только между соседними помещениями;
- мини-планировки в карточках тоже используют новый вид для первых 10 квартир;
- остальные квартиры пока не трогаются, их сделаем следующей партией;
- мебель, перетаскивание, поворот и цена с мебелью сохраняются.
