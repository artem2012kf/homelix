# Фикс дверей на планировке

Проблема была в том, что SVG-rect для зоны двери отображался как черный прямоугольник.
Теперь прямоугольники дверей удалены из отрисовки, а двери показываются тонкими линиями/проемами.

Замени файл:

components/ApartmentPlan.tsx

Потом открой:

app/globals.css

и в самый конец вставь содержимое файла:

ADD_TO_END_OF_app_globals.css

После этого:

cmd /c npm run build
git add .
git commit -m "исправить двери на планировке"
git push

На Vercel сделай Redeploy без кэша.
