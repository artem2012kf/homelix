# Финальный этап — все планировки

Это последняя партия. Теперь качественный генератор включён для всех квартир.

Что сделано:

- все оставшиеся квартиры подключены к нормальным схемам;
- теперь не важно, какой id у квартиры — компонент сам собирает адекватную планировку по комнатам;
- студии, 1-комнатные, евро-2, 2-комнатные, 3-комнатные и 4-комнатные используют разные шаблоны;
- двери остаются в старом стиле: белый проём + тонкая линия + дуга;
- двери ставятся только между соседними помещениями;
- мини-планировки в карточках тоже работают в новом стиле;
- мебель, перетаскивание, поворот и стоимость с мебелью сохранены.

Финальная партия включает оставшиеся квартиры:

- apt-604
- apt-649
- apt-702
- apt-748
- apt-811
- apt-858
- apt-930

Важно: я сделал не просто список id, а включил качественный генератор для всех квартир. Если в проекте окажется ещё одна квартира, она тоже получит нормальную схему, а не старый кривой полигон.
