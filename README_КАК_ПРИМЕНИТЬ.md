# Поворот мебели и итоговая стоимость

Что добавлено:

- мебель можно поворачивать на планировке;
- рядом с предметом появился круглый значок ↻;
- мебель также можно повернуть кнопкой "Повернуть" в списке;
- стоимость мебели прибавляется к цене квартиры;
- под планировкой теперь показывается:
  - стоимость квартиры;
  - стоимость мебели;
  - итого квартира + мебель.
