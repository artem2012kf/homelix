# Исправление ответа ИИ

Заменить файл:

app/api/chat/route.ts

Что изменено:
- На обычные вопросы типа «Как сделать входную зону удобнее?» ИИ больше не пишет стоимость, статус и лишний текст про объект.
- Про цену, бюджет и конкретное место установки ИИ говорит только если пользователь просит:
  «поставь ...», «размести ...», «расположи ...» или просит подобрать товар по бюджету.
- Для прихожей/входной зоны теперь возвращается нормальный практический ответ.
- Усилена очистка рассуждений thinking/reasoning.
