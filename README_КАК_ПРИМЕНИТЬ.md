# Нормальный дизайн всех планировок и дверей

Что сделано:

- обновлён дизайн планировок для всех квартир;
- комнаты стали аккуратнее: мягкие цвета, скругления, нормальная обводка;
- названия комнат больше не должны налезать друг на друга;
- двери теперь ставятся только там, где комнаты реально соприкасаются;
- убраны случайные двери по центру стен;
- убраны старые кривые внешние стены;
- мини-планировки в карточках квартир тоже стали аккуратнее;
- сохранено перемещение мебели мышью/пальцем;
- сохранён поворот мебели через кнопку под планировкой.

Замени файлы:

components/ApartmentPlan.tsx
components/ApartmentMiniPlan.tsx

Потом открой:

app/globals.css

и вставь в самый конец содержимое:

ADD_TO_END_OF_app_globals.css

Проверь:

cmd /c npm run build

Потом:

git add .
git commit -m "улучшить дизайн планировок и двери"
git push -u origin main
