# Сделать все квартиры разными

Что сделано:

- теперь каждая квартира получает свой вариант планировки по `id`;
- одинаковые типы квартир больше не выглядят одинаково;
- добавлены разные схемы:
  - лоджия сверху / справа / сбоку;
  - мокрые зоны слева / сверху / снизу;
  - разные позиции кухни-гостиной;
  - разные блоки спален;
  - разные схемы для студий, евро-2, 2-комнатных, 3-комнатных и 4-комнатных;
- двери остались старые: белый проём + линия + дуга;
- мебель, перетаскивание, поворот и цена с мебелью не ломаются.

Замени файл:

lib/apartment-plan-visuals.ts

Потом:

cmd /c npm run build
git add .
git commit -m "сделать планировки квартир разными"
git push -u origin main
