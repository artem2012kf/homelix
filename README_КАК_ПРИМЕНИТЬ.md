# Перемещение мебели мышью и пальцем

Что изменено:

- мебель теперь двигается прямо на планировке;
- нужно зажать предмет мышью или пальцем и перетащить;
- кнопка "Передвинуть" из списка мебели убрана;
- добавлена большая невидимая зона захвата, чтобы на телефоне было легче двигать мебель;
- во время перетаскивания страница не должна скроллиться.

Замени файлы:

components/ApartmentPlan.tsx
components/ApartmentExperience.tsx

Потом открой app/globals.css и вставь в самый конец содержимое:

ADD_TO_END_OF_app_globals.css

Проверь сборку:

cmd /c npm run build

Если все хорошо:

git add .
git commit -m "добавить перетаскивание мебели"
git push -u origin main
