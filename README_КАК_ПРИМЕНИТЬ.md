# Вернуть видимые планировки

Проблема была в том, что стили SVG могли не подхватиться или перебиться старыми CSS-блоками, поэтому комнаты стали чёрными.

Что исправлено:

- цвета комнат теперь прописаны прямо в компонентах, а не только через CSS;
- планировки больше не должны становиться чёрными;
- мини-планировки в карточках тоже исправлены;
- двери оставлены как простые белые проёмы без дуг;
- мебель, перетаскивание и поворот под планировкой сохраняются.

Замени файлы:

components/ApartmentPlan.tsx
components/ApartmentMiniPlan.tsx
types/furniture-placement.ts

Потом открой:

app/globals.css

и вставь в самый конец содержимое:

ADD_TO_END_OF_app_globals.css

Проверь:

cmd /c npm run build

Потом:

git add .
git commit -m "вернуть нормальный вид планировок"
git push -u origin main
