# Исправление для защиты: мебель по устройствам, параллельные запросы, ИИ и ручное перемещение

Что входит в архив:

1. Мебель теперь хранится отдельно на каждом устройстве.
   Если на одном ноутбуке поставить шкаф или кровать, на другом устройстве этой мебели не будет.
   Хранение идет в localStorage с уникальным device-id.

2. Можно отправлять несколько запросов подряд.
   Кнопка отправки больше не блокирует чат полностью.
   На странице квартиры и в "ИИ без комнат" показывается количество запросов в обработке.

3. "ИИ без комнат" снова показывает цену.
   Если спросить "лучшая квартира для семьи", "лучшая для аренды", "подбери квартиру" — в ответе будет цена, площадь, этаж и статус.

4. Мебель ставится логичнее.
   Алгоритм старается не ставить мебель на дверь и не перекрывать основной проход.
   Зоны двери подсвечены очень слабо, чтобы было понятно, куда мебель лучше не ставить.

5. Мебель можно двигать самому.
   После установки мебели ее можно перетащить мышью или пальцем прямо на планировке.
   Также остались команды: "передвинь шкаф", "убери кровать", "очисти всю мебель".
