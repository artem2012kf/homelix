# Чистая планировка без кривых дуг

Что исправлено:

- убраны все дуги дверей;
- двери теперь выглядят как обычные аккуратные проёмы;
- двери ставятся только:
  - из прихожей в комнаты;
  - на лоджию/балкон;
  - входная дверь в прихожую;
- убраны лишние случайные двери между всеми комнатами;
- комнаты снова прямые, без плиточного вида;
- внешний кривой контур убран;
- мини-планировки в карточках тоже обновлены;
- перемещение мебели мышью/пальцем сохранено;
- поворот мебели под планировкой сохранён.

Замени файлы:

components/ApartmentPlan.tsx
components/ApartmentMiniPlan.tsx
types/furniture-placement.ts

Потом открой:

app/globals.css

и вставь в самый конец содержимое:

ADD_TO_END_OF_app_globals.css

cmd /c npm run build
