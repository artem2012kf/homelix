# ЖК «Солнечный квартал» — интерактивный сайт застройщика

Готовый учебный проект сайта застройщика на Next.js: каталог квартир, мини-планы на карточках, интерактивные SVG-планировки, ИИ-консультант, история чата, регистрация, избранное, бронирование и магазин мебели.

## Основные возможности

- каталог из 30 квартир;
- сортировка по цене, площади, этажу, комнатности и ипотечному платежу;
- порядок показа квартир: свободные, затем бронь, затем проданные;
- мини-план квартиры на каждой карточке;
- отдельная страница квартиры с интерактивной SVG-планировкой;
- подсказки ИИ меняются при наведении и выборе комнаты;
- ИИ-чат с историей сообщений;
- отдельная страница общего ИИ-консультанта `/ai`;
- регистрация и вход по почте и паролю;
- личный кабинет `/account`;
- избранные квартиры;
- бронирование свободных квартир с обновлением статуса;
- серверная JSON-база `data/database.json`;
- SQL-схема для PostgreSQL/Supabase в `database/schema.sql`;
- магазин мебели `/furniture` с изображениями товаров.

## Стек

- Next.js App Router
- React
- TypeScript
- CSS без UI-библиотек
- OpenRouter API через backend route
- JSON-база для демонстрационного запуска

## Установка

```bash
npm install
```

Создайте файл `.env.local` на основе `.env.example`:

```env
OPENROUTER_API_KEY=your_openrouter_api_key_here
OPENROUTER_MODEL=qwen/qwen3-next-80b-a3b-instruct:free
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

Запуск на одном компьютере:

```bash
npm run dev
```

Запуск для открытия сайта с другого компьютера в одной Wi‑Fi сети:

```bash
npm run dev -- --hostname 0.0.0.0
```

После запуска откройте:

```text
http://localhost:3000
```

или по локальному IP, например:

```text
http://192.168.101.153:3000
```

## База данных

В текущей версии используется локальная JSON-база:

```text
data/database.json
```

Она хранит пользователей, сессии, избранное и бронирования. Для полноценного продакшена подготовлена SQL-схема:

```text
database/schema.sql
```

Ее можно использовать как основу для PostgreSQL или Supabase.

## Как работает пользовательский сценарий

1. Клиент открывает каталог квартир.
2. Сортирует варианты по цене, площади, этажу или платежу.
3. Смотрит мини-план прямо в карточке.
4. Открывает страницу квартиры.
5. Наводит на комнату и получает разные подсказки ИИ.
6. Задает вопрос ИИ-консультанту.
7. Регистрируется по почте и паролю.
8. Добавляет квартиру в избранное.
9. Бронирует свободную квартиру.
10. Видит избранное и брони в личном кабинете.

## ИИ-консультант

ИИ получает только нужный контекст: параметры квартиры, выбранную комнату, площадь, цену, преимущества, советы по мебели и короткую историю диалога. История сохраняется в браузере, поэтому чат не начинает каждый раз с приветствия.

Если `OPENROUTER_API_KEY` не указан, сайт продолжит работать, но ИИ будет отвечать в демонстрационном режиме.

## Магазин мебели

В разделе `/furniture` есть карточки мебели с изображениями, ценами, размерами, материалами, цветами, сроком доставки и тегами. Изображения находятся в:

```text
public/images/furniture
```

## Подготовка к сдаче

Проект оформлен как законченный прототип: есть главная страница, каталог, интерактивные планировки, ИИ-чат, авторизация, бронирование, избранное, база данных, магазин мебели и расширенный раздел «Как работает».


## ИИ-подбор мебели по бюджету

В карточке квартиры ИИ теперь умеет работать со сценарием подбора мебели:

1. Пользователь выбирает комнату на планировке.
2. Пользователь спрашивает, как лучше поставить кровать, диван, шкаф, стол или другую мебель.
3. ИИ сначала спрашивает бюджет мебели.
4. После ответа с ценой или диапазоном ИИ выбирает средний по цене вариант из каталога мебели.
5. Выбранная мебель появляется прямо на SVG-планировке квартиры.

Примеры запросов:

```text
Как лучше поставить кровать?
до 70 000 ₽
```

```text
Подбери диван в кухню-гостиную
40–90 тыс.
```

## Обновление: несколько предметов мебели и точечное перемещение

ИИ-подбор мебели на странице квартиры теперь работает как интерактивная расстановка:

- можно попросить поставить сразу несколько предметов, например `поставь кровать, шкаф и стол`;
- ИИ сначала уточняет бюджет, затем подбирает товары из магазина мебели;
- несколько предметов могут стоять в одной комнате одновременно;
- если не понравилось расположение одного предмета, можно написать `передвинь кровать` или `передвинь шкаф`;
- при таком запросе меняется только выбранный предмет, остальные остаются на месте;
- под планировкой есть ручные кнопки `Передвинуть` и `Убрать` для каждого предмета.


## Управление мебелью через чат

Кнопки управления мебелью под планировкой убраны. Теперь пользователь управляет расстановкой только текстом в ИИ-чате:

```text
передвинь кровать
убери шкаф
убери стол
очисти всю мебель
```

ИИ меняет только тот предмет, который указан в сообщении. Остальная мебель остается на месте.


## Исправление ограничения бесплатной модели OpenRouter

API-запросы к OpenRouter дополнительно сокращены, чтобы бесплатная модель реже возвращала ошибку по объему контекста:

- сокращается история чата;
- сокращается текст вопроса пользователя;
- в OpenRouter отправляются только компактные данные квартиры;
- уменьшен `max_tokens`;
- добавлен повторный короткий запрос, если первый ответ не прошел по лимиту.

Если бесплатная модель все равно ограничит запрос, сайт покажет понятный короткий ответ и предложит уточнить вопрос.


## Защита от ограничений бесплатной модели

Если бесплатная модель OpenRouter временно не принимает запрос из-за лимита, сайт больше не показывает пользователю техническую ошибку про объем запроса. Вместо этого API возвращает безопасный локальный ответ по данным квартиры или короткую подборку квартир из каталога.


## Очистка старых сообщений про лимит OpenRouter

Если у пользователя в браузере уже сохранился старый ответ вида «Запрос получился слишком объемным...», он автоматически удаляется из истории чата при следующей загрузке страницы. Также его можно убрать кнопкой «Очистить историю» в чате.
